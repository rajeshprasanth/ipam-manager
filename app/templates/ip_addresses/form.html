Helpful tips
  • Use CIDR-style prefix (e.g. 24 = /24).
  • MAC format: AA:BB:CC:DD:EE:FF.
  • Add up to 20 MAC addresses (one per interface); duplicates are ignored.
  • Set Reserved to hold an IP without assignment.
  • VLAN IDs are limited to 1–4094.
  • Pick a subnet so the address joins that subnet's inventory.
  • An address must fall inside the subnet it is linked to.
  • Mark exactly one address per device as primary.
